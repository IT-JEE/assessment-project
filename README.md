## Assessment Project (Junior Enterprises Europe)

This repository contains the assessment project for **IT Recruitment at Junior Enterprises Europe (JEE)**.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## UI Notes

- **Header**: white header bar with the JEE logo aligned to the top-right.
- **Blank page**: `src/app/page.tsx` is intentionally blank (starter canvas).

## Project Structure

- `src/app/layout.tsx`: global layout + header
- `src/app/page.tsx`: blank home page
- `public/assets/images/jee-logo.png`: logo used in the header
